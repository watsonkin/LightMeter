# 打赏 · 产品交互设计

对齐《Tips_Product_Spec.md》。美区三档：**$0.99 / $2.99 / $5.99**（界面用系统 `displayPrice`）。  
视觉稿见 `DesignOptions/tips-ui-*.jpg`。

---

## 1. 用户流程

```text
主界面
    │
    │  轻点左上角品牌「测光」
    ▼
打赏页（Sheet）
    │  默认选中「拜谢」($2.99)
    │
    ├─ 轻点某一档 ──► 仅切换选中态（不拉起支付）
    │
    ├─ 轻点「确定」──► 按当前选中档位进入 StoreKit 支付
    │                      │
    │                      ├─ 成功 ──► 致谢态 ──►「完成」关掉 Sheet
    │                      ├─ 取消 ──► 留在打赏页（选中态保留）
    │                      └─ 失败 ──► 短提示 + 可再点确定
    │
    └─ 关闭（下拉 / 取消）──► 回主界面
```

**原则：** 选档与支付分离；无「推荐」字样；默认中间档；成功不改变任何功能。

## 2. 界面结构

### 2.1 主界面入口（左上角）

| 元素 | 说明 |
|------|------|
| 位置 | 顶栏**左上角** |
| 展示 | 专用字形 **「测光」**二字（非系统默认字体，见字标设计） |
| 点击 | 直接弹出打赏 Sheet（无需先进入关于页） |
| 命中区域 | 不少于约 44×44 pt |
| 禁止 | 启动自动弹打赏；测光失败时诱导打赏 |

### 2.2 打赏页（Sheet，中等高度或近全屏）

自上而下：

1. **标题：** 支持测光表  
2. **主文案：** 感谢支持“测光”APP  
3. **副文案：** 您的支持是我不断迭代更新的动力  
   （界面**不写**「不会解锁任何功能」；产品事实仍是不解锁，仅不在 UI 强调）  
4. **三档（纵排，单选）：**

| 顺序 | 档位文案 | 价格（示例美区） | 默认 |
|------|----------|------------------|------|
| 1 | 感谢 | $0.99 | 否 |
| 2 | 拜谢 | $2.99 | **是（打开 Sheet 时默认选中）** |
| 3 | 跪谢 | $5.99 | 否 |

   - 选中：琥珀描边/浅底高亮  
   - **禁止**出现「推荐」角标或文案  
   - 轻点档位 = 改选中，**不**触发支付  

5. **主按钮：** 「确定」——仅此时按选中档位发起 IAP  
6. **页脚：** 费用将记入你的 Apple ID 账户  
7. **关闭：** 导航栏取消 / 下拉关闭  

**交互：**
- 商品未加载出：骨架或「加载中…」；确定按钮禁用。  
- 加载失败：「无法加载打赏选项」+「重试」。  
- 点击「确定」后按钮 Loading，防连点；档位选择可先锁定至交易结束。

### 2.3 购买中

- 「确定」按钮进入 Loading；系统购买表弹出。  
- 文案可选：正在向 Apple 确认…  
- 交易结束前不可再次点「确定」。

### 2.4 致谢态

- 主文案：**谢谢支持！**  
- 辅文案：感谢你对测光表的支持（可选）  
- 主按钮：**完成** → dismiss Sheet  
- 不自动跳 App Store 评分；不展示收据详情。

## 3. 状态机（实现用）

```text
idle → loadingProducts → ready
                ↘ failedProducts（可重试）

ready（默认 selected = tier2）
  → select(tier)           // 仅改选中
  → confirm → purchasing(selected)
                → success → thanks → dismiss
                → cancelled → ready（保持选中）
                → failed → ready + toast
```

## 5. 与主界面关系

- 打赏**唯一主入口**：顶栏左上角品牌「测光」（专用字标）。  
- **不**另放常驻大按钮「打赏」，避免挡取景。  
- 顶栏其余元素仍为：EV · 曝光补偿 · ISO。

## 7. 验收（交互）

- [ ] 从关于进入打赏 ≤ 2 次点击  
- [ ] 三档价格来自商店，美区沙盒可见 $0.99 / $2.99 / $5.99  
- [ ] 推荐档视觉可辨，但不自动扣款  
- [ ] 取消购买回到打赏页且可再点  
- [ ] 成功后致谢，测光功能无任何变化  
- [ ] 可连续打赏多次
